generated stand-ins (`Tools/artgen/lookalike.py` -> `Tools/mfport/work/generated/textures`, not
committed: re-created from `lookalikes.toml` / `lookalikes_auto.toml`, which keep the sampled
colours, so it works without the original game). Every file here must be legally
